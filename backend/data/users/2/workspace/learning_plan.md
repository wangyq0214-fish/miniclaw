## ⚠️ 常见易错点预警

1. **链式法则手动推导容易出错** → 先用小例子验证 (如 f(x)=x², g(x)=sin(x))
2. **卷积填充/步幅计算混乱** → 记住公式：Output = (Input + 2×Padding - Kernel)/Stride + 1
3. **过拟合时盲目调参** → 先观察训练/验证误差曲线，再决定用 Dropout/权重衰减/早停
4. **RNN 梯度消失** → 优先尝试 LSTM/GRU，避免深层单向 RNN
5. **注意力机制 Q/K/V 维度不匹配** → 画图确认每个矩阵的形状变化
