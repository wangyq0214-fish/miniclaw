# 大模型应用开发 · 拓展阅读清单

> 为 qin（智能科学与技术专业）定制  
> 生成时间：2025 年  
> 共 8 条推荐，覆盖入门 → 中阶 → 进阶

---

## ⭐ 入门

### 1. [Hugging Face LLM Course](https://huggingface.co/learn/llm-course/chapter1/1)
- **类型**: 在线教程 / 交互式课程
- **来源**: Hugging Face 官方
- **难度**: ⭐ 入门
- **时长**: 约 20-30 小时（12 章）
- **语言**: 英（部分章节有中文翻译）
- **摘要**: 由 Hugging Face 官方推出的免费 LLM 课程，从 Transformer 架构原理讲起，涵盖模型推理、微调、数据集处理、RLHF 等核心主题，并在最后介绍如何用 Gradio 构建和部署 LLM 应用 Demo。课程包含大量可运行的代码练习。
- **为什么推荐给你**: 作为智能科学与技术专业的学生，你已有深度学习基础。这门课程从原理到实践循序渐进，是系统性入门大模型应用开发的最佳起点，能帮你建立完整的知识框架。

## ⭐⭐ 中阶

### 2. [LangChain 官方文档 — Quickstart](https://docs.langchain.com/oss/python/langchain/quickstart)
- **类型**: 官方文档
- **来源**: LangChain 官网
- **难度**: ⭐⭐ 中阶
- **时长**: 约 30 分钟（快速上手）；深入学习需数小时
- **语言**: 英
- **摘要**: LangChain 是当前最流行的 LLM 应用开发框架。Quickstart 文档通过一个完整的 Agent 示例，展示如何安装依赖、配置 API Key、构建基础 Agent 并调用工具。文档还涵盖了 Agents、Tools、Memory、Retrieval 等核心组件的详细说明。
- **为什么推荐给你**: 掌握 LangChain 是 LLM 应用开发的"必修课"。你可以在已有 Python 编程能力的基础上，快速上手构建具备工具调用能力的 AI Agent，为后续的 RAG 和多 Agent 系统开发打下基础。

### 3. [OpenAI Cookbook](https://github.com/openai/openai-cookbook)
- **类型**: 开源项目 / 代码示例集
- **来源**: GitHub（OpenAI 官方）
- **难度**: ⭐⭐ 中阶
- **时长**: 按需查阅，每个 Notebook 约 15-30 分钟
- **语言**: 英
- **摘要**: OpenAI 官方维护的 Cookbook 仓库，包含 100+ 个实用 Notebook，覆盖 API 调用最佳实践、Prompt Engineering 技巧、RAG 实现、Function Calling、Embeddings 使用、文本分类等常见应用场景。每个示例都可直接运行。
- **为什么推荐给你**: 这是最贴近实际开发的参考资料。当你需要实现某个具体功能（如构建 RAG 系统或调用 Function Calling）时，可以直接找到对应的代码模板并修改使用，大幅提升开发效率。

### 4. [Chroma 向量数据库文档](https://docs.trychroma.com/docs/overview/introduction)
- **类型**: 官方文档
- **来源**: Chroma 官网
- **难度**: ⭐⭐ 中阶
- **时长**: 约 1-2 小时
- **语言**: 英
- **摘要**: Chroma 是一个开源的 AI 原生向量数据库，专为 LLM 应用中的 Embeddings 存储和检索而设计。文档介绍了如何创建 Collection、添加数据、配置 Embedding 函数、进行向量检索和元数据过滤，以及多模态检索等高级功能。
- **为什么推荐给你**: 向量数据库是 RAG（检索增强生成）应用的核心组件。Chroma 是最易上手的开源向量数据库，文档简洁清晰，适合你在构建自己的 RAG 应用时作为技术选型和实现参考。

### 5. [Hugging Face Transformers 文档](https://huggingface.co/docs/transformers/index)
- **类型**: 官方文档
- **来源**: Hugging Face 官网
- **难度**: ⭐⭐ 中阶
- **时长**: 按需查阅
- **语言**: 英
- **摘要**: Transformers 是 Hugging Face 的核心库，提供了 100 万+ 预训练模型的统一接口，支持文本、图像、音频、视频等多模态任务。文档涵盖 Pipeline 快速推理、Trainer 训练框架、generate 文本生成、模型微调等核心功能，是连接模型与应用的桥梁。
- **为什么推荐给你**: 作为智能科学与技术专业的学生，你需要了解如何加载和使用预训练模型。Transformers 库是业界标准工具，掌握它能让你在 LLM 应用开发中灵活调用各种模型。

### 6. [LangChain GitHub 仓库](https://github.com/langchain-ai/langchain)
- **类型**: 开源项目
- **来源**: GitHub
- **难度**: ⭐⭐ 中阶
- **时长**: 按需查阅
- **语言**: 英
- **摘要**: LangChain 的源码仓库（137k+ Stars），包含完整的框架代码、示例应用和测试用例。仓库结构清晰，分为 libs（核心库）、examples（示例代码）等目录。通过阅读源码可以深入理解 Agent 编排、工具调用、上下文工程等核心机制的设计思想。
- **为什么推荐给你**: 阅读优秀开源项目的源码是提升工程能力的最佳途径。当你使用 LangChain 遇到问题时，直接查看源码往往比查阅文档更高效，也能帮助你理解框架的设计哲学。

## ⭐⭐⭐ 进阶

### 7. [GPT-4 Technical Report](https://arxiv.org/abs/2303.08774)
- **类型**: 论文
- **来源**: arXiv（OpenAI）
- **难度**: ⭐⭐⭐ 进阶
- **时长**: 约 60-90 分钟
- **语言**: 英
- **摘要**: OpenAI 发布的 GPT-4 技术报告，详细介绍了 GPT-4 的模型架构、训练方法、能力评估和安全对齐策略。报告展示了 GPT-4 在各种基准测试上的表现，包括专业考试、多语言能力和视觉理解能力，是理解当代大模型能力边界的关键文献。
- **为什么推荐给你**: 理解底层模型的技术细节和能力边界，能帮助你在应用开发中做出更合理的技术决策——知道模型擅长什么、不擅长什么，才能设计出更好的 Prompt 策略和应用架构。

### 8. [DeepLearning.AI: LangChain for LLM Application Development](https://www.deeplearning.ai/short-courses/langchain-for-llm-application-development/)
- **类型**: 视频课程
- **来源**: DeepLearning.AI（由 LangChain 创始人 Harrison Chase 亲授）
- **难度**: ⭐⭐ 中阶
- **时长**: 约 1.5 小时
- **语言**: 英（含字幕）
- **摘要**: 由 DeepLearning.AI 推出的免费短课程，由 LangChain 创始人 Harrison Chase 亲自授课。课程通过视频讲解和代码演示，覆盖 LLM 应用开发的核心概念：Models、Prompts、Parsers、Memory、Chains、Agents 等，并结合实际案例展示如何构建完整的 LLM 应用。
- **为什么推荐给你**: 视频课程能帮助你更直观地理解 LLM 应用开发的工作流程。由框架创始人亲自讲解，能让你接触到最权威的设计理念和最佳实践，弥补纯文档阅读的不足。
