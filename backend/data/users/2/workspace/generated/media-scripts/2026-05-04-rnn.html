RNN 基本结构

为什么需要RNN？序列数据中，当前输出依赖于之前的信息

💡 为什么需要 RNN？

传统神经网络（MLP/CNN）假设输入样本相互独立。但语言、语音、视频等序列数据中，当前时刻的含义依赖于之前的上下文。RNN 通过隐藏状态 h 将历史信息传递到当前时刻。

速度
输入 x
隐藏状态 h
输出 y
RNN 单元

📝 核心公式

h_t = tanh(W_xh · x_t + W_hh · h_{t-1} + b_h)
y_t = W_hy · h_t + b_y
  • h_t：t 时刻的隐藏状态，编码了从序列开始到当前的所有历史信息
  • x_t：t 时刻的输入（如一个词的词向量）
  • W_xh, W_hh, W_hy：权重矩阵，所有时刻共享
  • tanh：激活函数，将隐藏状态压缩到 [-1, 1]

时间展开 (Unrolling Through Time)

将RNN沿时间轴展开，等价于一个很深的前馈网络

💡 展开的意义

RNN 虽然看起来只有一个单元，但按时间展开后，每个时刻都有一个"副本"。展开使我们能用标准的反向传播算法（BPTT）来训练 RNN。输入序列 "我 爱 深度 学习" 依次进入网络。

序列长度
速度

📝 关键理解

  • 展开后，RNN 等价于一个权重共享的深层网络
  • 每个时刻的 W_xh、W_hh、W_hy 都是同一组参数
  • 信息通过隐藏状态 h 从左向右流动，这就是"记忆"的来源
  • 序列越长，展开的层数越多 → 梯度消失/爆炸的风险越大

前向传播计算

手算一个简单的RNN前向传播，理解每一步的数值变换

💡 计算示例

假设输入维度=2，隐藏维度=3，序列长度=3。我们用具体数值演示每一步的矩阵运算。

📝 计算步骤

  • Step 1：初始化 h_0 = [0, 0, 0]（零向量）
  • Step 2：t=1 → 计算 tanh(W_xh·x_1 + W_hh·h_0) → 得到 h_1
  • Step 3：t=2 → 计算 tanh(W_xh·x_2 + W_hh·h_1) → 得到 h_2
  • Step 4：t=3 → 计算 tanh(W_xh·x_3 + W_hh·h_2) → 得到 h_3
  • Step 5：y = W_hy · h_3 → 最终输出

LSTM 门控机制

长短期记忆网络通过三个「门」控制信息的遗忘、输入和输出

💡 为什么需要 LSTM？

标准 RNN 的隐藏状态 h_t 在每一步都被 tanh "洗"一遍，长期信息很容易被覆盖。LSTM 引入了细胞状态 C_t（信息高速公路），通过遗忘门、输入门、输出门精确控制信息的保留与更新。

速度
遗忘门 f
输入门 i
输出门 o
细胞状态 C

📝 LSTM 四步计算

f_t = σ(W_f · [h_{t-1}, x_t] + b_f)    ← 遗忘门：决定丢弃哪些旧信息
i_t = σ(W_i · [h_{t-1}, x_t] + b_i)    ← 输入门：决定写入哪些新信息
C̃_t = tanh(W_C · [h_{t-1}, x_t] + b_C)    ← 候选细胞
C_t = f_t ⊙ C_{t-1} + i_t ⊙ C̃_t    ← 更新细胞状态
o_t = σ(W_o · [h_{t-1}, x_t] + b_o)    ← 输出门
h_t = o_t ⊙ tanh(C_t)    ← 输出隐藏状态
  • σ 是 sigmoid 函数，输出 0~1，相当于"阀门开关"
  • ⊙ 是逐元素乘法（Hadamard 积）
  • 细胞状态 C 通过加法更新（不是矩阵乘法），梯度可以无损流动

梯度消失与梯度爆炸

标准RNN难以学习长距离依赖，LSTM通过门控机制缓解此问题

💡 问题根源

BPTT 反向传播时，梯度需要经过多次矩阵乘法（W_hh 的连乘）。如果 W_hh 的特征值 < 1，梯度会指数衰减→消失；如果 > 1，梯度会指数增长→爆炸。这使得标准 RNN 难以学习超过 10~20 步的长距离依赖。

W_hh 缩放 1.0

📝 解决方案

  • 梯度裁剪 (Gradient Clipping)：当梯度范数超过阈值时等比缩小，防止爆炸
  • LSTM / GRU：通过门控机制创建"梯度高速公路"，让梯度可以无损地流过很长的距离
  • 残差连接：类似 ResNet 的跳跃连接，直接传递梯度
  • 正交初始化：将 W_hh 初始化为正交矩阵，特征值均为 1

🔄 GRU：LSTM 的简化版

GRU（门控循环单元）将 LSTM 的三个门简化为两个门：

z_t = σ(W_z · [h_{t-1}, x_t])    ← 更新门（合并遗忘+输入）
r_t = σ(W_r · [h_{t-1}, x_t])    ← 重置门
h_t = (1 - z_t) ⊙ h_{t-1} + z_t ⊙ tanh(W · [r_t ⊙ h_{t-1}, x_t])
  • GRU 没有单独的细胞状态 C，直接用 h 同时承担记忆和输出
  • 参数比 LSTM 少约 25%，训练更快，小数据集上表现相当
