卷积操作 (Convolution)

卷积核在输入特征图上滑动，逐元素相乘再求和，提取局部特征

💡 核心思想

卷积核（filter/kernel）是一个小矩阵（如 3×3），在输入图像上滑动，每到一个位置就做逐元素乘法 + 求和，生成输出特征图的一个像素值。公式：

Output[i,j] = Σ Σ Input[i+m, j+n] × Kernel[m, n]

📝 关键参数

  • 卷积核大小 (Kernel Size)：常用 3×3 或 5×5，核越大感受野越大
  • 步幅 (Stride)：卷积核每次滑动的距离。步幅=1 输出尺寸大，步幅=2 输出尺寸减半
  • 填充 (Padding)：在输入边缘补零，保持输出尺寸。常用 padding=1 配合 3×3 核
  • 输出尺寸公式：(N - K + 2P) / S + 1，其中 N=输入大小, K=核大小, P=填充, S=步幅

池化操作 (Pooling)

下采样特征图，减少参数量，增强平移不变性

💡 最大汇聚 vs 平均汇聚

池化在每个局部窗口中取最大值（Max Pooling）或平均值（Average Pooling），将特征图缩小。最常用的是 2×2 最大汇聚，步幅为 2，输出尺寸减半。

📝 池化的作用

  • 降维：减少特征图尺寸，降低后续计算量
  • 平移不变性：特征位置微小变化不影响池化结果
  • 防止过拟合：减少参数数量
  • 最大汇聚保留最显著特征，平均汇聚保留整体信息

CNN 整体架构

卷积层 → 激活函数 → 池化层 → ... → 全连接层 → 输出

💡 经典的 卷积-池化-全连接 架构

一个典型的 CNN 由特征提取部分（卷积层 + 池化层堆叠）和分类部分（全连接层）组成。卷积层逐层提取从低级（边缘、纹理）到高级（物体部件、整体）的特征。

📝 各层详解

  • 输入层：原始图像像素（如 224×224×3 的 RGB 图像）
  • 卷积层 (Conv)：用卷积核提取局部特征，输出特征图
  • 激活函数 (ReLU)：引入非线性，f(x) = max(0, x)
  • 池化层 (Pool)：下采样，减少空间维度
  • 全连接层 (FC)：将特征展平后做分类决策
  • 输出层 (Softmax)：输出各类别的概率分布

特征提取过程

CNN 逐层提取从低级到高级的特征：边缘 → 纹理 → 部件 → 物体

💡 层级特征抽象

CNN 的每一层都在做特征抽象。浅层卷积核检测边缘和颜色，中间层检测纹理和图案，深层检测物体部件（如眼睛、轮子），最终组合成完整物体的表示。

📝 为什么 CNN 如此强大？

  • 局部连接：每个神经元只看局部区域，大幅减少参数
  • 权值共享：同一个卷积核在所有位置共享参数，进一步压缩参数量
  • 层级抽象：逐层从低级特征组合出高级语义
  • 平移等变性：物体在图像中平移，特征图也相应平移
