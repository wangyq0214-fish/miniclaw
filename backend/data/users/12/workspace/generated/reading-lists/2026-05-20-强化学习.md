## ⭐ 入门级

### 1. OpenAI Spinning Up: Part 1 - Key Concepts in RL
- **类型**: 官方教程
- **来源**: OpenAI 官方文档
- **难度**: ⭐ 入门
- **时长**: 约 20 分钟阅读
- **语言**: 英文
- **摘要**: OpenAI 官方的强化学习入门教程，清晰定义了 Agent、Environment、State、Action、Reward、Policy、Value Function 等核心概念，并介绍了马尔可夫决策过程（MDP）的形式化定义。
- **为什么推荐给你**: 作为 OpenAI 官方出品的入门材料，语言简洁、结构清晰，适合作为强化学习的第一份阅读材料，帮助建立正确的概念框架。

**链接**: https://spinningup.openai.com/en/latest/spinningup/rl_intro.html

---

### 2. Gymnasium Basic Usage: Your First RL Program
- **类型**: 官方文档 + 代码示例
- **来源**: Gymnasium 官方文档 (Farama Foundation)
- **难度**: ⭐ 入门
- **时长**: 约 15 分钟阅读 + 动手实践
- **语言**: 英文
- **摘要**: Gymnasium 是强化学习的标准环境库（OpenAI Gym 的继任者）。本文档通过 CartPole 经典环境，手把手教你理解 Agent-Environment Loop，以及 `make()`、`reset()`、`step()`、`render()` 四个核心 API 的使用。
- **为什么推荐给你**: 强化学习离不开动手实验，Gymnasium 是最基础的工具链。通过这篇文档，你可以快速跑通第一个 RL 程序，获得直观的"试错学习"体验。

**链接**: https://gymnasium.farama.org/introduction/basic_usage/

## ⭐⭐ 中阶级

### 3. 【王树森】深度强化学习 (DRL) 完整课程
- **类型**: 视频课程（共 23 集）
- **来源**: B 站 / YouTube
- **难度**: ⭐⭐ 中阶
- **时长**: 约 10 小时（全套视频）
- **语言**: 中文
- **摘要**: 史蒂文斯理工学院王树森教授主讲的深度强化学习课程，涵盖基本概念、价值学习（SARSA、Q-Learning、DQN）、策略学习（REINFORCE、A2C）、Actor-Critic 方法、TRPO、连续控制、AlphaGo 原理以及多智能体强化学习。配套 GitHub 仓库提供完整的课件和中文笔记。
- **为什么推荐给你**: 这是中文世界最系统的深度强化学习视频课程之一，讲解循序渐进，数学推导清晰，配合课件笔记可以高效学习核心算法。GitHub 仓库（https://github.com/wangshusen/DRL）提供完整的 Slides 和 Notes_CN。

**链接**: https://www.bilibili.com/video/BV12o4y197US/

### 4. 🤗 Deep Reinforcement Learning Course (Hugging Face)
- **类型**: 交互式在线课程
- **来源**: Hugging Face 官方课程
- **难度**: ⭐⭐ 中阶
- **时长**: 约 20-30 小时（含动手实验）
- **语言**: 英文
- **摘要**: Hugging Face 出品的免费深度强化学习课程，从基础到前沿算法，涵盖 Q-Learning、DQN、PPO、A2C 等。课程特色是每个单元都配有 Google Colab 实战 Notebook，使用 Stable Baselines3 等主流库训练 Agent，还可以在 SnowballFight、Huggy 等趣味环境中测试你的 Agent。
- **为什么推荐给你**: 这门课程强调"理论+实践"结合，每个概念都有配套的可运行代码，适合喜欢边学边练的学习风格。完成后可获得 Hugging Face 官方认证证书。

**链接**: https://huggingface.co/learn/deep-rl-course/unit0/introduction

### 6. Lilian Weng: Policy Gradient Algorithms
- **类型**: 技术博客
- **来源**: Lilian Weng 个人博客 (OpenAI 研究员)
- **难度**: ⭐⭐⭐ 进阶
- **时长**: 约 40 分钟阅读
- **语言**: 英文
- **摘要**: OpenAI 研究员 Lilian Weng 的经典博客文章，系统梳理了强化学习的核心框架：从 MDP、Bellman 方程，到动态规划、蒙特卡洛方法、时序差分学习（SARSA、Q-Learning），再到策略梯度（REINFORCE、Actor-Critic、A3C），最后以 AlphaGo Zero 作为案例分析。文章数学推导严谨，同时配有直观的图示。
- **为什么推荐给你**: 这篇博客是强化学习领域引用率最高的综述性文章之一，适合作为系统性复习和深入理解的参考资料。当你学完基础课程后，这篇文章可以帮助你串联所有知识点，建立完整的知识图谱。

**链接**: https://lilianweng.github.io/posts/2018-02-19-rl-overview/

- **类型**: 论文阅读清单
- **来源**: OpenAI Spinning Up

- **时长**: 按需阅读（每篇论文约 1-2 小时）

### 8. Stable Baselines3 文档: RL Algorithms
- **类型**: 技术文档 / 库使用指南
- **来源**: Stable Baselines3 官方文档
- **难度**: ⭐⭐⭐ 进阶
- **时长**: 约 30 分钟阅读 + 实践
- **语言**: 英文
- **摘要**: Stable Baselines3 是最流行的强化学习算法库之一，提供了 PPO、A2C、DQN、SAC、TD3 等算法的高质量 PyTorch 实现。文档详细介绍了每种算法的原理、超参数调优建议、自定义环境接入方法，以及与 Gymnasium 的集成方式。
- **为什么推荐给你**: 理论学习的最终目标是能够动手实现和调试 RL 算法。Stable Baselines3 提供了工业级的实现，通过阅读其文档和源码，你可以理解算法从理论到工程落地的完整链路，为后续的研究或项目开发打下基础。

**链接**: https://stable-baselines3.readthedocs.io/en/master/guide/algos.html
