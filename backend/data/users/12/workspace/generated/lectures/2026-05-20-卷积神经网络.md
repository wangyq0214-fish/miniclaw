# 卷积神经网络（Convolutional Neural Network, CNN）

---

## 一、动机：为什么需要卷积神经网络？

### 1.1 全连接层处理图像的困境

在前面的学习中，我们使用**多层感知机（MLP）**处理图像数据时，通常的做法是将二维图像**展平为一维向量**输入网络。例如，一张 28×28 的灰度图像会被展平为长度 784 的向量。

> **具象类比**：想象你把一张照片撕成一条条纸带，然后拼接成一条长绳。这样一来，照片中"猫的耳朵在左上角"这种空间关系就完全丢失了。

这种方式存在两个严重问题：

| 问题 | 说明 |
|------|------|
| **参数爆炸** | 假设输入图像为 224×224×3（约 15 万个像素），隐藏层有 1000 个神经元，仅第一层就需要 **1.5 亿个参数**，计算和存储代价极高。 |
| **忽略空间结构** | 展平操作丢弃了像素之间的空间邻接关系，网络无法利用图像的**局部性**和**平移不变性**等先验知识。 |

### 1.2 图像的两个关键先验

人类视觉系统之所以高效，是因为它天然利用了图像的两个结构特性：

- **局部性（Locality）**：图像中的特征（如边缘、纹理）通常出现在**局部区域**，不需要同时观察整张图片就能检测到。
- **平移不变性（Translation Invariance）**：一只猫无论出现在图片的左上角还是右下角，它仍然是猫。特征的检测不应该依赖于它出现的**绝对位置**。

> **类比**：就像你用一个小放大镜在照片上逐区域扫描——放大镜只看局部（局部性），而且不管移到照片的哪个位置，同一个放大镜检测同一种特征（平移不变性）。

卷积神经网络正是基于这两个先验设计的，它通过**参数共享**和**局部连接**大幅减少参数量，同时保留了图像的空间结构信息。

## 二、核心概念：从全连接层到卷积

### 2.1 卷积的数学直觉

卷积操作的核心思想可以用一句话概括：**用一个小的"模板"（卷积核）在输入图像上滑动，在每个位置计算局部区域与模板的加权求和**。

形式化地，对于二维输入 $X$ 和卷积核 $K$，输出特征图 $Y$ 在位置 $(i, j)$ 的值为：

$$Y[i, j] = \sum_{m}\sum_{n} X[i+m, j+n] \cdot K[m, n]$$

> **类比**：卷积操作就像在黑暗中用手电筒（卷积核）照亮一张大地图（输入图像），手电筒的光圈很小，只能照亮局部区域。你拿着手电筒从左到右、从上到下逐格扫描，每次记录光圈内看到的"特征强度"（加权求和的结果），最终拼出一张新的"特征地图"。

### 2.2 互相关 vs. 卷积

严格数学意义上，上述操作实际上是**互相关（Cross-correlation）**运算。真正的卷积需要先将卷积核翻转 180° 再做加权求和。但在深度学习中，由于卷积核的权重是**通过学习得到的**，翻转与否不影响模型的表达能力，因此深度学习框架中所说的"卷积"实际上都是互相关运算，二者在实践中等价。

## 三、卷积层的基本元素

### 3.1 卷积层（Convolutional Layer）

卷积层是 CNN 的核心构建块，由一组可学习的**卷积核（kernel/filter）**组成。

**关键概念**：

| 概念 | 说明 |
|------|------|
| **卷积核** | 一个小尺寸的权重矩阵（如 3×3、5×5），在输入上滑动并做局部加权求和。 |
| **特征图（Feature Map）** | 卷积层的输出，每个卷积核生成一张特征图，表示在输入上检测到的某种特征。 |
| **感受野（Receptive Field）** | 输出特征图上某个元素在输入上能"看到"的区域大小。网络越深，感受野越大。 |

> **示例**：假设输入是一张 6×6 的灰度图像，使用一个 3×3 的卷积核（如 Sobel 边缘检测核），滑动步长为 1，不使用填充，则输出特征图大小为 4×4。每个输出元素由输入中一个 3×3 的局部区域计算得到。

### 3.2 填充（Padding）

卷积操作会使输出的空间尺寸**缩小**。如果输入大小为 $n_h \times n_w$，卷积核大小为 $k_h \times k_w$，则输出大小为 $(n_h - k_h + 1) \times (n_w - k_w + 1)$。

**填充**是在输入的边缘（上下左右）补零，以控制输出尺寸。

- **目的**：保持输出与输入的空间尺寸一致（"same" 填充），或精确控制输出大小。
- **公式**：若在高、宽方向分别填充 $p_h$ 和 $p_w$，则输出大小为：

$$\lfloor(n_h - k_h + p_h) / s_h + 1\rfloor \times \lfloor(n_w - k_w + p_w) / s_w + 1\rfloor$$

> **示例**：输入 5×5，卷积核 3×3，四周各填充 1 个零（padding=1），则输出仍为 5×5，保持了空间分辨率。

### 3.3 步幅（Stride）

步幅是卷积窗口每次滑动的**步长**，默认为 1。

- **增大步幅**可以快速降低输出的空间分辨率，减少后续计算量。
- 当步幅为 2 时，卷积窗口每次移动 2 个像素，输出尺寸大约减半。

> **类比**：步幅就像你扫描地图时的"跳跃幅度"。步幅为 1 是逐格扫描，步幅为 2 是隔一格跳一次。跳得越快，扫描越粗糙，但速度越快。

### 3.4 多输入多输出通道

实际的彩色图像通常有 3 个通道（R、G、B），因此卷积核也需要有对应的**深度维度**。

- **多输入通道**：若输入有 $c_i$ 个通道，卷积核的形状为 $k_h \times k_w \times c_i$。计算时，卷积核在每个通道上分别做卷积，然后将结果**求和**，得到一张输出特征图。
- **多输出通道**：使用 $c_o$ 个不同的卷积核，每个生成一张特征图，最终输出 $c_o$ 个通道。

> **示例**：输入为 3 通道的彩色图像（如 32×32×3），使用 16 个 3×3×3 的卷积核，则输出为 32×32×16（假设 same 填充、步幅 1）。这意味着我们同时检测了 16 种不同的局部特征。

**1×1 卷积层**：卷积核大小为 1×1，它不改变空间尺寸，只在**通道维度**上做线性组合，常用于调整通道数或引入非线性。

## 四、汇聚层（Pooling Layer）

### 4.1 为什么需要汇聚层？

卷积层提取了丰富的局部特征，但特征图仍然很大，且对位置过于敏感（目标稍微移动一点，特征图的值就会变化）。汇聚层的作用是：

1. **降低空间分辨率**：减少后续计算量和参数。
2. **扩大感受野**：让深层特征"看到"更大范围的输入。
3. **增强平移鲁棒性**：降低特征对精确位置的敏感性。

### 4.2 最大汇聚与平均汇聚

汇聚层在输入的局部窗口上计算**最大值（Max Pooling）**或**平均值（Average Pooling）**：

| 汇聚类型 | 计算方式 | 特点 |
|----------|----------|------|
| **最大汇聚** | 取窗口内最大值 | 保留最显著的特征，常用于网络前层 |
| **平均汇聚** | 取窗口内平均值 | 保留整体信息，常用于网络末层（如全局平均汇聚） |

> **示例**：对一个 4×4 的特征图使用 2×2 最大汇聚（步幅 2），输出为 2×2。每个 2×2 区域只保留最大值，分辨率减半。

```
输入 (4×4):          最大汇聚 (2×2, stride=2) → 输出 (2×2):
┌───┬───┬───┬───┐
│ 1 │ 3 │ 2 │ 1 │        ┌───┬───┐
│ 5 │ 6 │ 7 │ 8 │   →    │ 6 │ 8 │
│ 3 │ 2 │ 1 │ 0 │        ├───┼───┤
│ 1 │ 0 │ 2 │ 4 │        │ 3 │ 4 │
└───┴───┴───┴───┘        └───┴───┘
```

**重要特性**：汇聚层**没有可学习的参数**，它只是一个固定的下采样操作。

## 五、经典架构：LeNet

### 5.1 LeNet 的历史地位

LeNet 由 **Yann LeCun** 于 1989 年提出，是最早的卷积神经网络之一，用于手写数字识别。它定义了 **"卷积 → 池化 → 全连接"** 的 CNN 基本架构范式，为后来所有的 CNN 模型奠定了结构基础。

> **历史趣闻**：LeNet-5 曾被美国多家银行实际部署，用于自动读取支票上的手写数字，产生了巨大的商业价值。

### 5.2 LeNet-5 的网络结构

LeNet-5 的结构可分为两部分：

**卷积编码器**（提取特征）：
1. **卷积层 1**：5×5 卷积核，输出 6 个通道 → Sigmoid 激活 → 2×2 平均汇聚（尺寸减半）
2. **卷积层 2**：5×5 卷积核，输出 16 个通道 → Sigmoid 激活 → 2×2 平均汇聚（尺寸减半）

**全连接分类器**（做出预测）：
3. 展平 → 全连接层（120 个神经元）→ 全连接层（84 个神经元）→ 输出层（10 个神经元）

```
输入 (1×28×28)
  → Conv1 (6@24×24) → Sigmoid → AvgPool (6@12×12)
  → Conv2 (16@8×8)  → Sigmoid → AvgPool (16@4×4)
  → Flatten (256)
  → FC (120) → FC (84) → Output (10)
```

> **关键洞察**：与全连接层相比，LeNet 的参数量大幅减少。卷积层通过**参数共享**（同一个卷积核在所有位置复用）和**局部连接**（每个输出只与输入的局部区域相连）实现了高效计算。

## 六、CNN 的整体工作流程

将以上组件组合起来，一个典型的 CNN 图像分类流程如下：

```
输入图像
  │
  ▼
┌─────────────────────────────────────────┐
│  卷积层 + 激活函数（如 ReLU）            │  ← 提取局部特征
│  汇聚层（如最大汇聚）                    │  ← 降维、增强鲁棒性
│  ...（重复多次，逐步提取更高层特征）      │
└─────────────────────────────────────────┘
  │
  ▼
┌─────────────────────────────────────────┐
│  展平（Flatten）                         │
│  全连接层 + 激活函数                     │  ← 组合特征
│  输出层（如 Softmax）                    │  ← 分类预测
└─────────────────────────────────────────┘
  │
  ▼
预测结果（如：猫 / 狗 / 鸟 ...）
```

**特征层次化**：浅层卷积核学习到的是**边缘、纹理**等低级特征；深层卷积核学习到的是**眼睛、耳朵**等高级语义特征。这种从低级到高级的特征层次化是 CNN 的核心优势之一。

## 七、边界与常见误区

### 7.1 误区一："卷积核越大越好"

❌ 大卷积核（如 11×11）参数多、计算量大。现代网络普遍使用 **3×3 小卷积核**堆叠，既能达到大感受野，又能减少参数（如 VGG 网络证明了两层 3×3 卷积等效于一层 5×5 卷积）。

### 7.2 误区二："汇聚层一定需要"

❌ 汇聚层不是必须的。一些现代架构（如全卷积网络 FCN）完全用**带步幅的卷积层**替代汇聚层来实现下采样，效果同样出色。

### 7.3 误区三："CNN 只能处理图像"

❌ 虽然 CNN 最初为图像设计，但它的应用已扩展到**文本分类**（一维卷积）、**语音识别**、**视频分析**、**医学影像**、**自动驾驶**等领域。只要数据具有**局部相关性**，CNN 就可能适用。

### 7.4 误区四："更深的网络一定更好"

❌ 盲目增加网络深度会导致**梯度消失/爆炸**、**退化**等问题。ResNet 通过**残差连接**解决了退化问题，但网络设计仍需平衡深度、宽度和计算资源。

## 八、从 CNN 到更广阔的视野

CNN 是深度学习在计算机视觉领域的基石。掌握了 CNN 的基本原理后，你可以进一步探索：

| 方向 | 代表模型/技术 | 说明 |
|------|---------------|------|
| **更深的网络** | VGG、GoogLeNet、ResNet、DenseNet | 通过更巧妙的架构设计提升性能（详见第 6 章） |
| **目标检测** | R-CNN、Faster R-CNN、YOLO | 不仅识别"是什么"，还定位"在哪里" |
| **语义分割** | 全卷积网络（FCN）、转置卷积 | 对图像中的每个像素进行分类 |
| **注意力机制** | SENet、CBAM | 让网络学会"关注"重要的特征通道或空间位置 |
| **GPU 加速** | CUDA、数据并行 | CNN 的计算密集，GPU 是训练大规模 CNN 的必备工具 |

## 九、本章小结

| 核心概念 | 一句话总结 |
|----------|-----------|
| **卷积层** | 用可学习的小卷积核在输入上滑动，提取局部特征，通过参数共享大幅减少参数量。 |
| **填充（Padding）** | 在输入边缘补零，控制输出的空间尺寸。 |
| **步幅（Stride）** | 卷积窗口滑动的步长，增大步幅可降低输出分辨率。 |
| **多通道** | 多个卷积核生成多个特征图，每个检测不同类型的特征。 |
| **汇聚层** | 在局部窗口上取最大值或平均值，降维并增强平移鲁棒性。 |
| **感受野** | 输出元素在输入上能感知的区域范围，随网络深度增大。 |
| **LeNet** | 最早的 CNN 之一，定义了"卷积-池化-全连接"的架构范式。 |

> **学习建议**：理解 CNN 的关键在于动手实践。建议结合代码实现一个简单的 LeNet，在 MNIST 或 Fashion-MNIST 数据集上训练，直观感受卷积核学到的特征和网络的分类能力。
