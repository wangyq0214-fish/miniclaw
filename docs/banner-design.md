# Banner图设计方案

## 设计规格

- **尺寸**: 1280x640px
- **比例**: 2:1
- **格式**: PNG
- **背景**: 深色渐变

## 配色方案

### 背景
- 主色: #0F172A (深蓝黑)
- 渐变: #1E293B → #0F172A (左上到右下)

### 文字
- 标题: #FFFFFF (白色)
- 副标题: #94A3B8 (浅灰)
- 标签: #3B82F6 (蓝色)

### 技术栈标签
- 背景: #1E293B (深灰)
- 边框: #3B82F6 (蓝色)
- 文字: #FFFFFF (白色)

## 字体建议

### 中文
- 主标题: 思源黑体 Bold
- 副标题: 思源黑体 Regular

### 英文
- 主标题: Inter Bold
- 副标题: Inter Regular

## 设计元素

### 1. Logo区域
- 使用🎓或📚emoji作为项目图标
- 放在顶部居中

### 2. 标题区域
- "Mini-OpenClaw" 使用大号字体 (48-64px)
- 居中对齐

### 3. 副标题区域
- "AI Agent 教育辅助系统" 使用中号字体 (24-32px)
- 居中对齐

### 4. 功能亮点
- "文件驱动架构 · Agent全程可视化 · 11种技能"
- 使用小号字体 (16-20px)
- 居中对齐

### 5. 技术栈标签
- 4个标签水平排列
- 圆角矩形设计
- 居中对齐

## Figma设计步骤

### 1. 创建画板
- 新建 1280x640px 画板

### 2. 添加背景
- 填充渐变色 #1E293B → #0F172A

### 3. 添加文字
- 标题: "Mini-OpenClaw" (白色, 64px, Bold)
- 副标题: "AI Agent 教育辅助系统" (浅灰, 32px, Regular)
- 功能: "文件驱动架构 · Agent全程可视化 · 11种技能" (浅灰, 20px, Regular)

### 4. 添加技术栈标签
- 创建4个圆角矩形 (圆角: 8px)
- 填充: #1E293B
- 边框: #3B82F6, 1px
- 文字: "DeepAgents", "LlamaIndex", "Neo4j", "FastAPI"

### 5. 导出
- 导出为PNG格式
- 命名为 banner.png

## Canva设计步骤

### 1. 创建设计
- 选择"自定义尺寸" 1280x640px

### 2. 选择模板
- 搜索"科技"或"深色"模板
- 选择简洁风格

### 3. 修改内容
- 替换标题为 "Mini-OpenClaw"
- 替换副标题为 "AI Agent 教育辅助系统"
- 添加功能亮点文字

### 4. 添加技术栈
- 使用"形状"工具创建标签
- 添加文字 "DeepAgents", "LlamaIndex", "Neo4j", "FastAPI"

### 5. 下载
- 下载为PNG格式
- 命名为 banner.png
