# Demo GIF 制作指南

## 录制工具推荐

### 免费工具
1. **ScreenToGif** (Windows推荐)
   - 下载: https://screentogif.com
   - 优点: 简单易用，直接导出GIF
   - 操作: 录制 → 编辑 → 导出

2. **LICEcap** (Mac/Windows)
   - 下载: https://cockos.com/licecap
   - 优点: 轻量级，直接录制GIF
   - 操作: 调整窗口大小 → 录制

3. **OBS Studio** (专业)
   - 下载: https://obsproject.com
   - 优点: 功能强大，可录制高质量视频
   - 操作: 录制MP4 → 转换为GIF

## 录制步骤

### 使用ScreenToGif

1. **下载并安装**
   - 访问 https://screentogif.com
   - 下载Windows版本
   - 安装并打开

2. **设置录制区域**
   - 点击"录像机"
   - 调整录制框大小 (建议1280x720)
   - 将录制框放在项目界面上

3. **开始录制**
   - 点击"录制"按钮 (或按F7)
   - 执行要展示的操作
   - 点击"停止"按钮 (或按F8)

4. **编辑GIF**
   - 删除不需要的帧
   - 调整帧率 (建议15-20fps)
   - 裁剪画面

5. **导出GIF**
   - 点击"文件" → "另存为"
   - 选择GIF格式
   - 设置文件名: demo.gif
   - 保存到 docs/ 目录

### 使用LICEcap

1. **下载并安装**
   - 访问 https://cockos.com/licecap
   - 下载对应系统版本
   - 安装并打开

2. **设置录制窗口**
   - 调整LICEcap窗口大小
   - 将窗口放在要录制的内容上

3. **开始录制**
   - 点击"Record"
   - 选择保存位置
   - 输入文件名: demo.gif
   - 执行要展示的操作
   - 点击"Stop"

## GIF优化

### 在线工具
- https://ezgif.com
- 功能: 压缩、裁剪、调整帧率

### 优化步骤
1. 上传GIF到ezgif.com
2. 选择"Resize"调整尺寸 (1280x720)
3. 选择"Optimize"压缩大小
4. 目标大小: <5MB
5. 下载优化后的GIF

## 最终效果

### GIF规格
- **尺寸**: 1280x720px
- **时长**: 10-15秒
- **帧率**: 15-20fps
- **大小**: <5MB

### 内容要求
- 展示核心功能
- 操作流畅自然
- 无敏感信息
- 画面清晰

## 常见问题

### Q: GIF太大怎么办？
A: 使用ezgif.com压缩，或降低帧率到15fps

### Q: 画面模糊怎么办？
A: 确保录制区域足够大，导出时选择高质量

### Q: 录制时有敏感信息？
A: 使用示例数据，避免真实用户信息

### Q: Mac怎么录制？
A: 使用LICEcap或QuickTime Player
